# ICIS Website

A static, multi-page institutional website project with university and organization information, blog pages, and reusable inner-page layouts.

## Pages

- `index.html` — landing page
- `aboutICIS.html` and `aboutUniversity.html` — organization and university information
- `blog.html` and `blog-single.html` — blog listing and article layout
- `inner-page.html` and `portfolio-details.html` — supporting page templates

## Run locally

Open `index.html` in a browser, or serve the repository root with any static file server so the relative asset paths resolve.

The pages use local assets and vendor stylesheets from the repository. The project is a static front end and does not require a backend.
